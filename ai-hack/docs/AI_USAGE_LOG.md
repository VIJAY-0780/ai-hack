## AI Tools Used

Two AI tools were used during development:

1. GitHub Copilot
2. ChatGPT

---

## 1. GitHub Copilot

GitHub Copilot was used during implementation as a coding assistant.

It assisted with writing and completing code for the React/Vite application, including UI components, application functionality, styling, and data handling.

Copilot suggestions were reviewed and modified by the developer as needed.

The developer remained responsible for feature decisions, implementation choices, testing, and the final code.

---

## 2. ChatGPT

ChatGPT was primarily used for debugging, troubleshooting, deployment assistance, and submission preparation.

### Debugging

ChatGPT helped troubleshoot:

- npm/build errors
- Project directory and repository structure issues
- Git-related issues
- Vite configuration problems
- Production build errors

The developer executed commands locally and verified the results.

### Deployment

ChatGPT helped troubleshoot deployment problems encountered while deploying the project to Vercel.

This included:

- Vercel build failures
- Project/root directory configuration
- Build command configuration
- Missing `package.json` errors
- Vite deployment configuration

The application was successfully deployed after correcting the deployment configuration.

### Submission Preparation

ChatGPT was also used to review the project against the hackathon requirements, including repository accessibility, live demo availability, Git history, documentation, and AI Usage Log requirements.

---

## AI vs Human Contribution

AI tools were used as development assistants.

GitHub Copilot assisted with implementation and coding.

ChatGPT was primarily used for debugging, troubleshooting, deployment assistance, and submission preparation.

The developer was responsible for the project concept, feature decisions, code review, testing, Git operations, deployment configuration, and final submission.
