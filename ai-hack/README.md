# 🚀 ABTalks 60-Day Challenge

A 60-day building challenge web application designed to encourage developers to build consistently, share their progress, and become more visible to recruiters.

https://hackathon-1-lac.vercel.app

## ✨ About the Project

ABTalks 60-Day Challenge is a web application created around the idea of maintaining a consistent development journey over 60 days.

The application provides a simple starting point for a structured challenge where developers can build, share, and document their progress.

The project focuses on encouraging developers to:

- Build consistently
- Share their progress
- Track their development journey
- Create a visible record of their work
- Improve their professional visibility
